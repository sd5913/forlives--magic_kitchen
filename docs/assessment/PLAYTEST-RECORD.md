# Playtest record / 试玩记录

This is an unfilled record, not evidence of a completed trial. Use one copy per actual session. The course requires another person to experience the project; trying before an explanation is a useful way to check learnability, not an additional requirement stated in the group brief. A public name or signature is not requested by that brief.

本页为待填记录，不代表已完成试玩。每次真实试玩填写一份。课程要求他人体验；先不解释玩法有助检查可理解性，但不是小组要求新增的硬性条件。当前要求未要求公开姓名或签名。

Tasks: read and accept a ticket; use stations to make a wrap; inspect another ticket and return without losing progress; try one mistake/correction; deliver and interpret the score. Record only tasks actually attempted, with timing only if measured.
