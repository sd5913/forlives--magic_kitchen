# Roasting station high fidelity / 烘烤区高保真

This archive contains only the roasting station design and its assets. Extract all six ZIP files into the same folder; each archive uses the same Roasting_Assets root.
本次归档仅包含烘烤区高保真及其素材。六个压缩包解压至同一文件夹，合并 Roasting_Assets 目录即可。

- Six 1536 × 1024 state previews: waiting, undercooked, ready, burnt, removed and sliced.
- Six separate transparent duck assets: three hanging doneness states, raw duck lying down, cooked duck lying down, and a full platter of sliced duck.
- Scene backgrounds, tray labels, doneness track and pointer, recognition feedback, order tickets and gesture-card assets.
- 六张1536 × 1024状态界面；六个独立透明鸭子素材；背景、托盘标签、火候条与指针、识别提示、小票及手势卡素材。

See components.json for the component-to-file mapping and layout_manifest.json for layout information. Screens are design previews, not game screenshots; the package contains no gameplay code. The original three screens are Figma exports; the three later screens are locally revised previews whose scene backgrounds have also been applied in Figma. PNG/SVG exports do not preserve Figma component links or prototype interactions.
组件对应文件见 components.json，位置见 layout_manifest.json。界面为设计预览，不是游戏运行截图。原三张为Figma导出，补充三张为局部修订预览，其背景已同步替换进Figma。导出图片不保留Figma组件关联及原型连线。

Editable source / 可编辑源文件：[烘烤区高保真](https://www.figma.com/design/OUk4C7fCqrzPmnOuzZpYGZ/forlives--magic_kitchen?node-id=195-1371)

Asset processing records are retained in docs/. Existing low-fidelity files and other stations are outside this update.
素材处理记录保留在 docs/。本次不更新原有低保真及其他工作区。
